How to send a large file for free, without uploading it

Email stops at about 20 to 25 MB, and most free upload services cap you at a few gigabytes. Across sends the file straight from your browser to theirs instead, so there is no upload step, no account and no copy left on a server.

Send it in four steps

  1. Open acrossfile.com on the computer or phone that has the file.
  2. Drop the file on the page, or press Choose a file. Nothing is uploaded yet: the file stays on your device.
  3. Send the link you get by chat, text or email. If the other device is in the same room, let it scan the QR code, or type the six-letter code at acrossfile.com.
  4. Keep your page open. When they press Download, the file streams straight to them, encrypted the whole way.

Send a file now

Why this works for big files

Upload services copy your file to their servers first, then the other person downloads it again. That is two full trips, a storage cap, and a copy that sits on someone else’s computer until it expires.

Across skips the middle. Your browser and theirs connect directly with WebRTC, the technology video calls use, and the file goes once, from you to them. Chrome, Edge and Firefox write it to disk as it arrives, so even a file bigger than the receiver’s memory works.

How big can the file be?

  • Same Wi-Fi, or with Hide my IP address turned off: the two browsers connect directly and we set no size limit. The practical limits are your connection and the receiver’s free disk space.
  • Through the relay (the default): Hide my IP address sends the encrypted file through a relay so neither of you sees the other’s address. Everyone shares the relay’s daily and monthly allowance, so a very large transfer can stop partway if it runs out. For a file of tens of gigabytes, turn the switch off on both sides.
  • iPhone, iPad and Safari: these hold the whole file in memory until it finishes, so the page warns before downloading anything over 1 GB there. For a very large file, receive it on a computer with Chrome, Edge or Firefox.

Tips for a fast, smooth transfer

  • Most transfers are limited by the sender’s upload speed. Across compresses text, logs, spreadsheets and other data that shrinks well while it sends, which can make them several times faster. Video and zip files are already compressed, so they go as they are.
  • Both of you need to be online at the same time, and your page must stay open until the download finishes. On a phone, come back to the page after sharing the link, because the phone pauses pages in the background.
  • Across sends one file at a time. To send a folder or many files, zip them into one file first.
  • On the same network, the file goes over your local network and doesn’t leave it, which is usually the fastest route of all.

When another tool is the better choice

If the other person can’t be online while you send, an upload service or a shared cloud folder is the better fit, because it holds the file until they’re ready. Across trades that for privacy and no size cap: nothing is stored, so there is nothing to wait in a server. See how Across compares.
