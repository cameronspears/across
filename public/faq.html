Across Send a file

Questions and answers

Across sends a file straight from one browser to another, encrypted, with no account and nothing stored on a server. Here are the questions people ask most.

Send a file now

Is Across free?

Yes. There is no paid plan, no account and no ads. Because files never touch our servers, there is no storage to pay for.

How big a file can I send?

On the same Wi-Fi, or with Hide my IP address turned off, the browsers connect directly and we set no size limit. Through the relay, which hides your IP address, everyone shares a daily and monthly allowance, so a very large transfer can stop partway if it runs out. iPhone, iPad and Safari hold the whole file in memory, so the page warns before downloading more than 1 GB there. More in how to send a large file.

Does the other person need to be online at the same time?

Yes. The file streams from your browser to theirs, so your page must stay open until their download finishes. If they can’t be online while you send, an upload service like WeTransfer is the better fit.

Do I need to install an app or make an account?

No. Across runs in any current browser, such as Chrome, Edge, Firefox or Safari, on a phone or a computer. There is nothing to install and nothing to sign up for.

Does it work between iPhone, Android, Windows and Mac?

Yes, in any direction. Open acrossfile.com on both devices, pick the file on one, and type the six-letter code or scan the QR code on the other. See sending between a phone and a computer.

Can Across see my file?

No. The file is encrypted end to end between the two browsers. The secret that protects it sits in the link after the #, which browsers never send to a website. Before any data moves, each browser proves it knows the secret, so a server in the middle would be caught. How Across works explains every step, and the code is open source.

Will the other person see my IP address?

Not by default. Hide my IP address is on, so your browser connects only through an encrypted relay and the other person sees the relay’s address, not yours. Turning it off connects you directly, which can be faster but shows each of you the other’s address.

Can I send a folder or several files?

Across sends one file at a time. To send a folder or many files, zip them into one file first.

How long does the link work?

For as long as your page stays open. Close the tab and the link stops working, since there is no copy anywhere else. Anyone with the link or code can download the file while it’s open, so share it like a password.

Can several people download the same file?

Yes. Anyone you send the link to can download it while your page is open.

How fast is it?

Usually as fast as the sender’s upload allows. On the same Wi-Fi, the file goes over the local network, which is often much faster. Across also compresses text, logs and other data that shrinks well while it sends.

What happens if the transfer stops halfway?

Nothing is kept, so it starts over: open the link again while the sender’s page is open, or ask them to send the file again. A phone that locks its screen or switches apps pauses the page, so keep the sending phone on the Across page until it finishes.
